About Code Breaker

A logic puzzle based on a famous board game. The computer hides a secret code of four coloured pegs. You make a guess, and it tells you how close you are with little clue pins: a black pin for each peg that's the right colour in the right spot, and a white pin for each peg that's a right colour but in the wrong spot. It doesn't say which pegs they are, so you have to reason it out. Crack the code before you run out of rows. Hard mode has five pegs and eight colours.

How to play

Tap colours or 1–8Add a peg
BackspaceRemove a peg
Enter / ✓Check the guess

Tips

  • The clue pins don't tell you WHICH peg is right, only how many.
  • Colours can repeat in the code.
  • Change one thing at a time to learn exactly what matters.

How to get better at Code Breaker

Code Breaker is about getting the most information from every guess. A good first guess uses two colours, like red-red-blue-blue. The clues tell you how many reds and blues are in the code, and roughly where.

Then change things carefully. If you move one peg and the black count goes up, you learned where that colour belongs. If it goes down, you learned where it doesn't. Changing too much at once makes the clues hard to read.

Remember that the total of black and white pins equals how many of your colours are in the code. Once that total equals the number of pegs, you have all the right colours, and you just need the order.

From beginner to expert

  • Beginner: Crack a code on Easy.
  • Getting good: Crack a Normal code in 6 tries or fewer.
  • Expert: Crack a Hard code.

Did you know?

Mathematicians proved that any 4-peg, 6-colour code can always be cracked in five guesses or fewer, if you play perfectly.

Questions players ask

Can colours repeat?

Yes, the code can use the same colour more than once.

What do the pins mean?

⚫ = right colour, right place. ⚪ = right colour, wrong place.
