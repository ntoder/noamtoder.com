How to install

🪟 Windows

  1. Download the Setup .exe file.
  2. Open it from your Downloads folder.
  3. If a blue box says "Windows protected your PC", click More info, then Run anyway. This shows up because the app is new, not because something is wrong.
  4. NoamBrowser installs and opens by itself.

🍎 Mac

  1. Check Apple menu → About This Mac. Apple M chip: download the arm64 file. Intel: download the x64 file.
  2. Double-click the zip and drag NoamBrowser into Applications.
  3. Open Terminal, paste xattr -cr /Applications/NoamBrowser.app and press Enter (only once).
  4. Open NoamBrowser from Applications.

🐧 Linux

  1. On Ubuntu, Debian, Mint and similar, download the .deb file.
  2. Open Terminal and run sudo apt install ~/Downloads/noambrowser_*_amd64.deb
  3. Other Linux: download the AppImage, allow it to run as a program, and double-click it.

You only install once. After that, NoamBrowser updates itself.

Questions

Is NoamBrowser free?

Yes, completely free, including the VPN, the ad blocker and the account.

Is it safe?

Windows and Mac show a warning for any app that hasn't paid Microsoft or Apple for a signing certificate. NoamBrowser's full source code is public on GitHub, so anyone can check what it does.

Do I need an account?

No. The account is optional and only needed if you want to sync between computers or use NoamChat on more than one device.
