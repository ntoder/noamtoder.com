How to solve Sudoku: techniques from easy to hard

By Noam · 15 November 2026 · 8 min read

The rule of Sudoku fits in one sentence: every row, every column and every 3×3 box must contain the numbers 1 to 9 exactly once. Yet hard puzzles can feel impossible. The secret is that a well-made Sudoku never needs guessing. Every number can be worked out with logic, and a small set of techniques is enough to solve almost everything. Here they are, from easiest to hardest.

Start where there's least to think about

Look for a row, column or box that is almost full. If eight numbers are already there, the ninth is obvious. Even with six or seven filled in, there are only a few options to check. Filling these in early gives you more clues for everything else.

Technique 1: scan one number at a time

Pick a number, say 7. Look at each 3×3 box that doesn't have a 7 yet. For each empty square in that box, check whether a 7 already appears in the same row or column. If only one square in the box is left where a 7 could go, it must go there. Then do the same for 8, then 9, and so on. This "cross-hatching" solves most easy puzzles completely.

Technique 2: the only number that fits

Sometimes it's easier to look at one square instead of one number. Check its row, its column and its box, and list every number already used. If eight different numbers appear, the square can only be the ninth. This works well for squares in busy parts of the grid.

Technique 3: use notes

On medium and hard puzzles, you'll reach a point where nothing is obvious. That's when to switch on notes. In our Sudoku game, press N and pencil in every possible number for each empty square. It takes a minute, but it turns a puzzle you can't see into one you can. Every time you place a number, remove it from the notes in the same row, column and box.

Technique 4: naked singles and hidden singles

With notes in place, look for two things. A naked single is a square with only one note left; that's the answer. A hidden single is a number that appears in the notes of only one square in a row, column or box. Even if that square has other notes, the hidden number must go there, because nowhere else can take it.

Technique 5: pairs

If two squares in the same row each have exactly the same two notes, say 3 and 8, then those two squares will hold the 3 and the 8 between them. That means no other square in that row can be a 3 or an 8, so you can erase those notes everywhere else in the row. The same works in columns and boxes. Pairs are often the key that unlocks a hard puzzle.

Technique 6: pointing

Suppose that inside one box, all the squares that could hold a 5 are in the same row. The 5 for that box must be somewhere in that row, so no square in the rest of the row, outside the box, can be a 5. Erase those notes. This technique sounds complicated, but once you've seen it a few times, you'll spot it quickly.

Common mistakes

  • Guessing. If you guess and you're wrong, the mistake can hide for a long time. Our game ends after three mistakes, so it pays to be sure.
  • Forgetting to update notes. Every number you place removes options elsewhere. Clean up your notes right away.
  • Staring at one area. If you're stuck, move to a different part of the grid, or scan a different number.

A fun fact

A Sudoku needs at least 17 starting numbers to have only one solution. This was proved by mathematicians using a huge computer search in 2012. Our puzzles always have exactly one answer, so the logic above will always get you there.
