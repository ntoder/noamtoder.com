How to install

1. Put it in Applications

  1. Open the file you downloaded.
  2. Drag Noam's Game Hub onto the Applications folder.

2. Open it the first time

  1. Open Terminal (press Command-Space and type Terminal).
  2. Paste xattr -cr "/Applications/Noam's Game Hub.app" and press Enter.
  3. Open the Game Hub from Applications or Launchpad. You only do this once.

Or without Terminal

  1. Open the app. When the Mac says it can't check it, click Done.
  2. Go to System Settings → Privacy & Security, scroll down and click Open Anyway.

The Mac shows this warning for any app that hasn't paid Apple for a signing certificate. It doesn't mean something is wrong.

No download? Use Safari

On macOS Sonoma or newer, open noamtoder.com in Safari, then click File → Add to Dock. You get a Game Hub icon in your Dock with no download at all.
