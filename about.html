What this site is

Noam's Game Hub is a collection of free games that run right in your web browser, on a computer, a tablet or a phone. There's nothing to install. You open a game and play.

It started with Noametry, the first game I built and the one the hub is named after. Over time it grew into a full arcade: classics like Snake and Block Drop, thinking games like Chess and Sudoku, sports games like Penalty Shootout, word and learning games like Word Guess and Flag Quiz, and creative tools like Pixel Paint.

Every game page has a guide underneath it: how to play, the controls, a strategy section for getting better, and a bit about where that kind of game comes from. The articles go deeper, with longer guides and some behind-the-scenes posts about how games are made.

Who makes it

I'm Noam. I build web projects in HTML, CSS and JavaScript, and I run a coding club where kids learn to make their own websites and games. Building games is the best way I know to learn to code, and it's how I teach it too.

I also make NoamBrowser, a free, private web browser for Windows, Mac and Linux with a built-in ad blocker and VPN.

That's also why I care about how the games feel. I play-test each one on a computer and on a phone, tune how hard it is, and fix things when players tell me something is off. If a game here is too hard, too easy, or broken on your device, I really do want to know.

How the games are built

Every game is written by hand in JavaScript and drawn on an HTML <canvas>, the same technology I explain in How a browser game works. There are no plug-ins and no app stores. The games share a small toolkit I wrote for things like sound effects, touch controls and saving your best score, so a fix in one place improves every game.

If you'd like to try making one yourself, Make your first game in 30 lines of JavaScript is a great first project to try.

Keeping it friendly and safe

  • You can play without an account. An account is free and only adds things like saved scores, leaderboards and achievements.
  • Ads are kept child-safe. The site is supported by ads from Google, and our ad requests ask Google to treat visitors as children, so ads are not personalised. Premium removes ads completely.
  • Comments are filtered. Rude words, links and phone numbers are blocked, players can report a comment, and I remove anything unkind.
  • Online games are with friends only. You play online by sharing a private room code with someone you know. There's no chatting with strangers, just emoji reactions.

You can read exactly what is stored and why in the privacy policy, and the rules for using the site in the terms.

Found a bug, have an idea for a game, or want to say hi? Email me at noam@noamtoder.com. I read every message. Teachers who want to use a game in class are very welcome to write too.
